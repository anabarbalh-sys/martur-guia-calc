MARTUR GUIA CALC

Aplicativo web instalável (PWA).

COMO USAR:
1. Publique esta pasta em um endereço HTTPS.
2. Abra o endereço no Chrome/Edge do celular.
3. Use o menu do navegador e escolha "Instalar app" ou "Adicionar à tela inicial".
4. O Martur Guia Calc será aberto como aplicativo.

Observação: o navegador normalmente exige HTTPS para instalação de PWA. Abrir o arquivo index.html localmente permite usar a calculadora, mas pode não permitir a instalação como app.
